# Input data

**The data files themselves are not tracked on this branch.** They are third-party scientific
data — an atomic mass evaluation, charge distribution and shell correction systematics, a
resonance parameter library, and experimental fragment mass yields. None of it originates with
this work, and the MIT licence covering the code does not extend to it. Each collection carries
the terms and the attribution of its own source.

They were tracked in the import commit `bdba1d9`, so the exact bytes the thesis calculations ran
against remain recoverable from history:

```
git show bdba1d9:input_data/AME2020.ANA > AME2020.ANA
git checkout bdba1d9 -- input_data/          # the whole tree, in one go
```

The code reads from `input_data/` flat and from the per-nuclide subdirectories named in
`options.jl`; restoring the tree from that commit puts every file back where it expects it.

## Layout

| Path | Content | Format |
|---|---|---|
| `AME2020.ANA` | mass excesses, 3558 nuclides | `Z A symbol D σD`, keV, no header |
| `Aux files/AUDI95.ANA` | the superseded 1995 evaluation, unused by the thesis runs | as above |
| `Aux files/SZSN.GC` | shell corrections for the Gilbert-Cameron systematic, `n` = 11 … 150 | `n S(N) S(Z)`, MeV, one header line |
| `Aux files/B2MOLLER.ANA` | ground-state quadrupole deformations | `Z A β₂`, one header line |
| `Aux files/resonances0.dat` | s-wave resonance parameters, the source of `S₀(A)` | commented header, `S₀` in units of 10⁻⁴ |
| `Cf-252/DeltaZ_rms_A.CF52` | charge polarization and dispersion | `A ΔZ rms`, one header line |
| `Cf-252/CF52YATKE.VES` | pre-neutron fragment mass yield `Y(A,TKE)` | `A TKE Y σY`, one header line |
| `Pu-239/DeltaZ_rms_A.PU39` | charge polarization and dispersion | `A ΔZ rms` |
| `Pu-239/P9YATKE.ANA` | `Y(A,TKE)` | `A TKE Y σY` |
| `Pu-239/P9YATKE1.CHI` | `Y(A,TKE)` | `A TKE Y`, no uncertainty column |
| `U-235/DeltaZ_rms_A.U5` | charge polarization and dispersion | `A ΔZ rms` |
| `U-235/U5YATKE.ANA` | `Y(A,TKE)` | `A TKE Y σY` |
| `U-235/U5YATKE.SRE` | `Y(A_H,TKE)`, heavy-fragment indexed | `A_H TKE Y σY` |
| `U-235/EXTRADEF.U5` | extra-deformation energies for the scission-modelling partition | `A Z ΔE_def`, MeV |

`DeltaZ_rms_A.PU39`, `P9YATKE.ANA` and `P9YATKE1.CHI` also sat loose at the root of
`input_data/`, because the reader takes some paths flat and some per nuclide. The loose
`P9YATKE1.CHI` is not a copy of the one under `Pu-239/`: it is that file after
`Data conversion/addNaNtoYield.jl`, which appended a fourth column of `NaN` and in doing so
overwrote the header line that carried the provenance annotation.

## Sources

**`AME2020.ANA`** — the 2020 atomic mass evaluation.
W. J. Huang, M. Wang, F. G. Kondev, G. Audi, S. Naimi, *Chinese Physics C* **45**, 030002 (2021);
M. Wang, W. J. Huang, F. G. Kondev, G. Audi, S. Naimi, *Chinese Physics C* **45**, 030003 (2021).
Distributed by the Atomic Mass Data Center. `Aux files/AUDI95.ANA` is the 1995 evaluation it
superseded.

**`Aux files/SZSN.GC`** — shell corrections `S(N)` and `S(Z)`.
A. Gilbert, A. G. W. Cameron, *Canadian Journal of Physics* **43**, 1446 (1965), as distributed in
the IAEA Reference Input Parameter Library.

**`Aux files/B2MOLLER.ANA`** — ground-state quadrupole deformations from the finite-range
liquid-drop model.
P. Möller, J. R. Nix, W. D. Myers, W. J. Swiatecki, *Atomic Data and Nuclear Data Tables* **59**,
185 (1995), via RIPL.

**`Aux files/resonances0.dat`** — s-wave average resonance parameters, from which the neutron
strength function `S₀(A)` used by the variable evaporation cross section is parameterized.
IAEA Reference Input Parameter Library, RIPL-3: R. Capote *et al.*, *Nuclear Data Sheets* **110**,
3107 (2009).

**`*/DeltaZ_rms_A.*`** — charge polarization `ΔZ(A)` and the root-mean-square dispersion `rms(A)`
of the isobaric charge distribution, for `CF52` (²⁵²Cf), `U5` (²³⁵U) and `PU39` (²³⁹Pu).
A. C. Wahl, *Atomic Data and Nuclear Data Tables* **38**, 1 (1988).

**`Cf-252/CF52YATKE.VES`** — pre-neutron fragment mass yield against total kinetic energy for
²⁵²Cf(SF). This is the distribution behind every chapter 4 result of the thesis.

**`U-235/U5YATKE.SRE`** — ²³⁵U(n_th,f) yields measured by C. Straede *et al.*, as the file's own
header records.

**`Pu-239/P9YATKE1.CHI`** — ²³⁹Pu(n_th,f) yields, the Chiba set, dated 25 July 2023 in the file
header.

**`U-235/EXTRADEF.U5`** — extra-deformation energies `ΔE_def = E_def(β₂^sc) − E_def(β₂^a.t.)`,
generated by `Data conversion/generateDeltaEdeformation.jl` from `Aux files/B2MOLLER.ANA`. No
equivalent file exists for ²⁵²Cf: the thesis obtained its scission-modelling result through the
`E*_H/TXE (A_H)` parameterization instead, so the scission-modelling partition was exercised by
²³⁵U alone.

Experimental yields used in any published result should cite the measurement, not this
repository.
